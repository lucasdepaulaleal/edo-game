# 🎮 EDO's Player

O **EDO's Player** é um jogo educativo interativo desenvolvido para facilitar o ensino e a aprendizagem de **Equações Diferenciais Ordinárias (EDOs)**. Através de uma abordagem *hands-on*, o projeto permite que estudantes explorem conceitos matemáticos complexos de forma visual e lúdica.

## 📚 Tópicos Abordados

O jogo foca em aplicações práticas de EDOs de primeira ordem, incluindo:

* **Resfriamento Newtoniano:** Estudo da variação de temperatura de um corpo em relação ao meio.
* **Crescimento Populacional:** Modelagem da evolução de populações ao longo do tempo.
* **Decaimento Radioativo:** Análise da desintegração de elementos químicos.

## 🛠️ Tecnologias Utilizadas

* **Frontend:** HTML5 e CSS3 (Design modular e responsivo).
* **Lógica:** JavaScript Vanilla (Manipulação de DOM e lógica do quiz).
* **Assets:** Utilização de fontes personalizadas (ArcadeClassic, Minecraft) para uma estética retro e áudio de fundo para imersão.
* **Deployment:** Configurado para GitHub Pages via GitHub Actions.

## 🚀 Funcionalidades

1. **Módulo "Vamos Aprender!":** Seção teórica detalhada com explicações didáticas sobre as fórmulas e aplicações de cada tipo de EDO.
2. **Módulo "Vamos Jogar!":** Um quiz interativo para testar os conhecimentos adquiridos de forma prática.
3. **Interface Imersiva:** Controle de áudio (Play/Pause) e navegação intuitiva através de botões estilizados.

## 📂 Estrutura do Projeto

* `/assets`: Contém imagens das equações, ícones da interface e arquivos de áudio.
* `/explicacao`: Páginas HTML dedicadas ao conteúdo teórico de cada modelo matemático.
* `/quiz`: Estrutura lógica e visual do desafio interativo.
* `/fonts`: Tipografias personalizadas para o tema do jogo.
* `index.html`: Ponto de entrada principal da aplicação.

## 🔧 Como Executar

Como o projeto é baseado em tecnologias web padrão, basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador moderno.
